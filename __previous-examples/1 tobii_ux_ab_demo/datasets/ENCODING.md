# Kodowanie datasetu

`ux_ab_demo.csv` jest zapisany jako **UTF-8 bez BOM** i z normalizacją Unicode NFC.

Nie zapisuj go jako ANSI / Windows-1250. Jeśli edytujesz plik w Excelu,
przy eksporcie wybierz **CSV UTF-8**.

Jeżeli w PsychoPy zamiast polskich liter pojawiają się kwadraty/prostokąty,
problem dotyczy fontu, a nie kodowania CSV.
